# Baseline Profile for BlackBerry Keyboard
# Optimizes cold start by pre-compiling critical startup paths
#
# Every rule below must name a class that actually exists in the APK. Verified
# against the source tree on 2026-09-06 during the package rearchitecture; if you
# move or rename a class, move its rule here in the same commit.
#
# Wildcards (audit H-10, 2026-11): "*" matches within one path segment, "**" across
# segments, and "->**(**)**" is every method of the matched classes. AGP expands them
# against the release dex (through the R8 mapping) when it compiles the binary
# profile. They cover the packages on the cold-start, first-field and per-keystroke
# paths, which used to run interpreted until background dexopt had collected a
# profile of its own (releases are sideloaded, so there are no cloud profiles).
# Settings screens, backup, language-pack downloads and the personal-dictionary UI
# stay out on purpose. Check a change with:
#   profgen validate app/src/main/baseline-prof.txt
